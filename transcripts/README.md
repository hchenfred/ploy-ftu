## How to add a session

- **Claude app chat:** Share (top right) → create link → paste it in the table. Re-share after later messages: a link is a snapshot.
- **Claude Code:** run `/export transcripts/<NN>-<topic>.txt` before ending the session, then add a row above.
- **Other tools:** export or copy the conversation as text into this folder, then add a row above.

Start with `../NOTES.md` for the key decisions and overrides; it points to the interesting parts of these transcripts.
